# 部署文档总览

本文档汇总了 XT-Music 项目各模块的部署方案，覆盖前端、后端、Android App 全链路部署。

## 端口与环境速查表

| 模块 | 默认端口 | 环境变量前缀 | 推荐部署方式 |
|------|---------|-------------|-------------|
| music-server | 3000 | 无 | Docker / 原生 Node |
| music-web | 3000 (dev) | NEXT_PUBLIC_ | Vercel / Docker |
| music-admin | 3001 (dev) | NEXT_PUBLIC_ | Vercel / Docker |
| music-twa | - | - | APK/AAB 分发 |

- [ ] 前端页面可正常访问

- [ ] 前端可正常调用后端 API（无跨域问题）
- [ ] 登录功能正常
- [ ] 歌曲播放正常
- [ ] 管理后台可正常访问

- [ ] 防火墙端口已开放

## 安全加固指南

### 1. 修改默认密码
- 管理员默认密码 `admin123` 必须修改
- JWT_SECRET 必须替换为随机字符串

### 2. 配置 HTTPS
- 生产环境必须使用 HTTPS
- 推荐使用 Let's Encrypt 免费证书
- 宝塔面板可一键申请 SSL 证书

### 3. 配置防火墙
- 只开放必要端口（80、443）
- 数据库端口（如使用外部数据库）不对外暴露
- 使用安全组或 iptables 限制访问

### 4. 定期备份
- 数据库每日自动备份
- 上传文件定期备份
- 保留最近 30 天备份

详细安全加固指南请参考：
- [安全加固指南](../operations/security.md)

## 监控与告警

### 1. 健康检查
- 后端提供 `/api/health` 健康检查接口
- 建议配置定时监控（每 1-5 分钟检查一次）

### 2. 日志管理
- 后端日志输出到控制台和文件
- 建议使用 ELK 或 Loki 进行日志收集
- 关键操作（登录、修改、删除）记录操作日志

### 3. 告警配置
- 服务不可用时告警
- 磁盘空间不足时告警
- 错误率过高时告警

详细内容请参考：
- [监控与告警](../operations/monitoring.md)

## 性能优化建议

### 前端
- 启用 Gzip/Brotli 压缩
- 配置 CDN 加速静态资源
- 使用图片懒加载
- 启用 PWA 离线缓存

- 配置适当的缓存策略
- 数据库查询优化
- 使用 CDN 加速音频和图片文件

### 数据库
- 定期清理历史数据
- 优化慢查询
- 定期备份

详细内容请参考各模块部署文档。

## 备份与恢复自动化

### 数据库备份
- SQLite 数据库：直接复制 `.db` 文件
- 建议每日自动备份
- 备份文件保留至少 30 天

### 文件备份
- 上传的音频文件和图片
- 建议同步到对象存储或其他服务器

### 恢复流程
1. 停止服务
2. 恢复数据库文件
3. 恢复上传文件
4. 重启服务
5. 验证功能正常

详细内容请参考：
- [备份与恢复](../operations/backup-recovery.md)

## 常见问题

### 端口被占用
- 检查是否有其他进程占用端口
- 使用 `lsof -i :3000`（Linux）或 `netstat -ano | findstr 3000`（Windows）查看
- 修改端口号或停止占用进程

### 跨域问题
- 检查后端 `CORS_ORIGINS` 配置
- 确保前端域名在白名单内
- 检查 Nginx 配置

### 数据库连接失败
- 检查数据库文件路径是否正确
- 检查文件权限
- SQLite 无需端口，确保路径正确

更多常见问题请参考各模块部署文档。
