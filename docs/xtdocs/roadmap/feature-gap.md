# 功能差异与开发计划

本文档基于对现有音乐平台功能的系统性对比分析，明确 XT-Music 项目已实现、部分实现和未实现的功能，并制定分阶段的开发计划。

## 已完善模块清单

以下模块功能已基本完善，可投入生产使用：

### ✅ 后端服务（music-server）
- 用户认证（注册/登录/JWT）
- 歌曲/专辑/歌手/歌单 CRUD
- 收藏、播放历史
- 搜索功能
- 管理后台接口
- 文件上传（本地/S3/COS）
- 应用版本管理
- 操作日志

### ✅ 前端用户端（music-web）
- 发现页（Banner、推荐、新专辑、热门歌手）
- 排行榜（热歌榜、新歌榜、飙升榜、原创榜）
- 搜索（歌曲/专辑/歌手/歌单）
- 音乐库（我的歌单、收藏）
- 个人中心
- 全屏播放器（歌词、进度、音量、音质切换）
- 迷你播放栏
- 直播场次 / 歌切列表与详情
- 每日推荐（歌曲 / 歌切）
- 相似歌曲（歌手详情页）
- 歌单分类（标签筛选）
- PWA 支持
- 亮/暗色主题 + 颜色主题
- 平台更新日志（自 v1.4.3 起从后台拉取）

### ✅ 管理后台（music-admin）
- 数据看板（Android App 版本徽标 + Web 平台版本徽标双轨展示）
- 歌曲/专辑/歌手/歌单管理
- Banner 管理
- 用户管理
- 系统设置
- 应用版本管理（App 端）
- 平台更新日志管理（Web 平台端，自 v1.4.3 起）
- 操作日志

### ✅ Android 客户端（music-twa）
- WebView 加载前端 PWA
- JSBridge 双向通信
- 原生 Media3 播放引擎
- 后台播放、通知、锁屏控件
- 应用内更新

## 技术债务与优化项

| 项目 | 优先级 | 说明 |
|------|--------|------|
| 代码规范统一 | 高 | ESLint/Prettier 配置统一 |
| Git 工作流 | 中 | PR 流程、Code Review 规范 |
| 错误边界 | 中 | 前端错误边界、优雅降级 |
| 图片优化 | 中 | WebP 格式、CDN 图片处理 |
| 懒加载 | 低 | 路由级和组件级代码分割 |
| 虚拟列表 | 低 | 长列表性能优化 |
| Bundle 分析 | 低 | 定期分析并优化包体积 |
| TypeScript 严格模式 | 中 | 启用 strict 模式，完善类型定义 |

## 贡献指南

如需参与开发：

1. Fork 本仓库
2. 创建功能分支：`git checkout -b feature/your-feature`
3. 提交更改：`git commit -m 'Add some feature'`
4. 推送分支：`git push origin feature/your-feature`
5. 提交 Pull Request

请确保：
- 代码通过 lint 检查
- 必要的单元测试已通过
- 文档已同步更新
- Commit 信息符合 Conventional Commits 规范
