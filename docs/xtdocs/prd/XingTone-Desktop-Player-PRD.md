# XingTone 桌面端音乐播放器 — 产品需求文档 (PRD)

| 字段 | 内容 |
|------|------|
| **项目名称** | xingtone-desktop-player |
| **语言** | 中文 |
| **技术栈** | Electron + React + TypeScript + MUI + Tailwind CSS + Zustand + Vite |
| **音频方案** | HTML5 Audio API |
| **版本** | v1.0 |
| **日期** | 2025-01 |
| **原始需求** | 为 XingTone 音乐流媒体平台开发桌面端播放器客户端，对接已有 NestJS 后端 API，提供完整的音乐发现、播放、管理体验 |

---

## 1. 产品目标

| # | 目标 | 衡量指标 |
|---|------|----------|
| G1 | **提供沉浸式音乐播放体验**：实现低延迟、高稳定性的音频播放，支持歌词同步、播放队列管理与音质切换，让用户在桌面端获得不低于 Web 端的听歌体验 | 首次播放启动延迟 < 2s；播放器崩溃率 < 0.1%；歌词同步偏差 < 200ms |
| G2 | **打造高效的音乐发现与检索能力**：整合发现页、排行榜、搜索、直播歌切等内容入口，让用户能快速找到想听的音乐 | 搜索结果首屏加载 < 1s；发现页完整渲染 < 2s；核心路径（搜索→播放）≤ 3 次点击 |
| G3 | **构建个人化的音乐管理空间**：支持歌单创建与管理、收藏、播放历史、下载等功能，让用户的音乐资产可沉淀、可迁移 | 歌单操作响应 < 500ms；收藏状态切换即时反馈；离线下载文件完整率 > 99% |

## 2. 用户画像与场景

### 2.1 用户画像

| 画像 | 描述 | 核心诉求 |
|------|------|----------|
| **日常听众** | 每天听歌 1-3 小时的普通用户，主要在办公/学习时使用桌面端 | 快速找到喜欢的歌、稳定播放、歌词跟唱、收藏喜欢的歌曲 |
| **音乐探索者** | 喜欢发现新音乐的用户，关注排行榜和新专辑 | 发现页推荐质量高、搜索精准、能按歌手/专辑浏览深挖 |
| **直播粉丝** | 关注特定歌手直播的歌切内容的用户 | 能浏览直播场次合集、快速定位和播放歌切、收藏感兴趣的场次 |
| **歌单管理者** | 喜欢整理音乐、创建主题歌单的用户 | 灵活的歌单管理（创建/排序/批量操作）、歌单封面自定义 |

### 2.2 核心使用场景

1. **后台播放场景**：用户在桌面端工作时，将播放器最小化或置于迷你模式，持续播放背景音乐，通过系统托盘或快捷键控制播放
2. **主动发现场景**：用户打开播放器，浏览发现页推荐内容，或通过搜索/排行榜找到目标歌曲后立即播放
3. **深度聆听场景**：用户播放专辑或歌单，查看同步歌词，调整音质，构建播放队列连续聆听
4. **内容整理场景**：用户创建歌单，将收藏的歌曲批量添加到歌单中，调整播放顺序，管理个人音乐库

## 3. 用户故事

| # | 角色 | 需求 | 价值 |
|---|------|------|------|
| US1 | 作为听众 | 我想要登录账号后自动恢复上次播放状态 | 以便继续上次未听完的音乐，无需重新查找 |
| US2 | 作为听众 | 我想要在搜索框输入关键词后快速获得歌曲/专辑/歌手/歌切结果 | 以便高效找到想听的内容 |
| US3 | 作为听众 | 我想要播放音乐时看到同步滚动的歌词 | 以便跟唱或了解歌曲内容 |
| US4 | 作为听众 | 我想要将喜欢的歌曲一键收藏 | 以便日后快速回听，构建个人音乐库 |
| US5 | 作为听众 | 我想要创建自定义歌单并管理歌曲顺序 | 以便按场景（运动/工作/睡前）组织音乐 |
| US6 | 作为听众 | 我想要切换音质（高/中/低） | 以便在网络条件不同时平衡音质与流畅度 |
| US7 | 作为听众 | 我想要浏览直播歌切合集 | 以便回看喜欢歌手的直播精彩片段 |
| US8 | 作为听众 | 我想要将播放器切换到迷你模式 | 以便在屏幕空间有限时仍能控制播放 |
| US9 | 作为听众 | 我想要查看播放历史 | 以便找回最近听过的歌曲 |
| US10 | 作为听众 | 我想要使用键盘快捷键控制播放/暂停/切歌 | 以便在不切换窗口的情况下快速操作 |

## 4. 需求池

### P0 — 必须实现（MVP 核心闭环）

| ID | 需求 | 关联 API | 说明 |
|----|------|----------|------|
| P0-01 | 用户注册与登录 | `POST /auth/register`, `POST /auth/login` | JWT Token 存储，登录态持久化，支持记住登录状态 |
| P0-02 | 首页/发现页 | `GET /discover` | 展示 Banner 轮播、推荐歌曲、新专辑、热门歌手、热门歌单 |
| P0-03 | 音乐播放核心 | `GET /songs/:id` → `fileUrl` | 基于 HTML5 Audio API 实现，支持播放/暂停/上一首/下一首 |
| P0-04 | 播放控制条 | — | 进度条拖拽、当前时间/总时长显示、音量调节、播放模式切换（顺序/单曲循环/随机） |
| P0-05 | 歌词显示 | `GET /songs/:id/lyric` | LRC 歌词解析与同步滚动，当前行高亮，支持点击跳转 |
| P0-06 | 综合搜索 | `GET /search`, `GET /search/hot` | 关键词搜索，支持分类筛选（歌曲/专辑/歌手/歌切），展示热门搜索词 |
| P0-07 | 歌曲列表展示 | `GET /songs` | 分页加载，支持排序，点击歌曲行直接播放 |
| P0-08 | 全局播放器状态管理 | — | Zustand 管理播放状态，跨页面切换时播放不中断 |
| P0-09 | Token 鉴权拦截器 | — | Axios 请求拦截器自动携带 Bearer Token，401 时跳转登录 |
| P0-10 | 应用版本检查 | `GET /app/version/latest` | 启动时检查更新，提示用户升级 |

### P1 — 重要（核心体验增强）

| ID | 需求 | 关联 API | 说明 |
|----|------|----------|------|
| P1-01 | 我的歌单管理 | `GET/POST/PUT/DELETE /user/playlists` | 创建/编辑/删除歌单，歌单封面展示 |
| P1-02 | 歌单歌曲管理 | `POST /user/playlists/:id/songs`, `DELETE`, `PUT reorder` | 批量添加歌曲、移除歌曲、拖拽排序 |
| P1-03 | 歌曲收藏 | `POST /user/favorites`, `GET /user/favorites` | 收藏/取消收藏，收藏列表浏览，歌曲行收藏状态实时同步 |
| P1-04 | 播放历史 | `GET/POST /user/history`, `DELETE` | 自动记录播放历史，支持查看/删除单条/清空 |
| P1-05 | 专辑详情浏览 | `GET /albums/:id` | 展示专辑信息+歌曲列表，支持整专辑播放 |
| P1-06 | 歌手详情浏览 | `GET /artists/:id`, `/artists/:id/songs`, `/artists/:id/clips` | 歌手信息、代表作、歌曲列表、歌切列表 |
| P1-07 | 直播歌切浏览 | `GET /live-sessions`, `GET /live-sessions/:id`, `GET /live-sessions/clips` | 场次列表→场次详情→歌切播放，跨场次歌切聚合浏览 |
| P1-08 | 播放队列管理 | — | 当前播放队列展示，支持拖拽排序、删除、清空，队列持久化 |
| P1-09 | 音质切换 | `GET /songs/:id/qualities`, `GET/PUT /user/preferences/quality` | 查看可用音质，切换音质，记住用户偏好 |
| P1-10 | 迷你模式 | — | 窗口缩小为迷你播放器，显示歌曲信息+核心控制按钮 |
| P1-11 | 公开歌单浏览 | `GET /playlists`, `GET /playlists/:id/songs` | 浏览官方/公开歌单，查看歌单歌曲并播放 |
| P1-12 | 排行榜 | `GET /rankings` | 按播放量/收藏量查看排行榜 |
| P1-13 | 站点设置 | `GET /settings/site` | 获取站点配置信息（站点名、Logo等） |
| P1-14 | 收藏扩展 | `POST/GET /user/albums/:id/favorite`, `/user/playlists/:id/favorite`, `/user/live-sessions/:id/favorite`, `/user/live-clips/:id/favorite` | 专辑/歌单/直播场次/歌切的收藏与状态查询 |

### P2 — 锦上添花（体验优化）

| ID | 需求 | 关联 API | 说明 |
|----|------|----------|------|
| P2-01 | 下载管理 | `GET /songs/:id/download-url`, `GET /user/downloads` | 预签名直链下载，下载进度展示，下载记录查看 |
| P2-02 | 主题切换 | — | 亮色/暗色主题切换，记住用户偏好 |
| P2-03 | 全局快捷键 | — | 播放/暂停(MediaPlayPause)、上一首(MediaPreviousTrack)、下一首(MediaNextTrack)、音量调节 |
| P2-04 | 系统托盘 | — | 最小化到托盘，托盘菜单快捷操作，关闭窗口时最小化到托盘选项 |
| P2-05 | 音乐可视化 | — | 基于 Web Audio API 的频谱可视化效果，播放时在播放器区域展示 |
| P2-06 | 个人资料管理 | `GET/PATCH /user/profile`, `POST /user/upload/avatar`, `POST /user/password` | 修改昵称/头像、修改密码 |
| P2-07 | 每日推荐 | `GET /discover/daily-songs`, `GET /discover/daily-clips` | 每日随机推荐歌曲/歌切入口 |

## 5. UI/UX 设计要点

### 5.1 整体布局风格

采用 **三栏式经典布局**（参考 Spotify / 网易云音乐桌面端）：

```
┌─────────────────────────────────────────────────────────┐
│  ┌──────────┐ ┌──────────────────────────────────────┐  │
│  │          │ │                                      │  │
│  │  侧边    │ │         主内容区域                    │  │
│  │  导航栏  │ │   (发现页/搜索/歌单/专辑/歌手等)       │  │
│  │          │ │                                      │  │
│  │  - 发现  │ │                                      │  │
│  │  - 搜索  │ │                                      │  │
│  │  - 我的  │ │                                      │  │
│  │    音乐  │ │                                      │  │
│  │  - 直播  │ │                                      │  │
│  │    歌切  │ │                                      │  │
│  │          │ │                                      │  │
│  │  ┌────┐  │ │                                      │  │
│  │  │用户│  │ │                                      │  │
│  │  │头像│  │ │                                      │  │
│  │  └────┘  │ │                                      │  │
│  └──────────┘ └──────────────────────────────────────┘  │
│  ┌─────────────────────────────────────────────────────┐ │
│  │  ▶ 播放控制栏 (歌曲信息 | 进度条 | 控制按钮 | 音量)  │ │
│  └─────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────┘
```

### 5.2 导航结构

| 导航项 | 子项 | 说明 |
|--------|------|------|
| **发现** | — | 发现页：Banner轮播 + 推荐歌曲 + 新专辑 + 热门歌手 + 热门歌单 |
| **搜索** | — | 搜索输入框 + 热门搜索 + 搜索结果（分Tab：歌曲/专辑/歌手/歌切） |
| **我的音乐** | 收藏 | 收藏的歌曲列表 |
| | 歌单 | 用户创建的歌单列表，点击进入歌单详情 |
| | 播放历史 | 最近播放记录 |
| | 下载 | 下载管理（P2） |
| **直播歌切** | — | 直播场次列表 → 场次详情 → 歌切播放 |
| **排行榜** | — | 播放榜 / 收藏榜 |

### 5.3 播放器布局（底部固定栏）

| 区域 | 内容 |
|------|------|
| **左侧** | 当前播放歌曲封面 + 标题 + 歌手名 + 收藏按钮 |
| **中间** | 上一首 / 播放暂停 / 下一首 + 进度条（当前时间 / 总时长） + 播放模式切换 |
| **右侧** | 音质标签 + 音量滑块 + 播放队列按钮 + 迷你模式按钮 + 歌词面板按钮 |

### 5.4 歌词面板

- 点击播放器右侧歌词按钮，从底部滑出/弹出歌词面板
- LRC 歌词逐行滚动，当前播放行高亮放大居中
- 点击任意歌词行跳转到对应时间点
- 支持歌词面板与主内容区域并排展示（桌面端宽屏优势）

### 5.5 设计规范

| 维度 | 规范 |
|------|------|
| **色彩** | 主色调参考品牌色，暗色模式为主（音乐播放器场景），支持亮色切换 |
| **字体** | 系统默认无衬线字体，中文优先 PingFang SC / Microsoft YaHei |
| **图标** | Material Icons（MUI 内置），风格统一 |
| **间距** | Tailwind CSS 间距系统，卡片圆角 8-12px |
| **动效** | 页面切换淡入淡出，按钮 hover 微动效，歌词滚动平滑过渡 |
| **响应式** | 窗口宽度 < 900px 时侧边栏折叠为图标模式 |

## 6. 非功能性需求

### 6.1 性能

| 指标 | 要求 |
|------|------|
| 应用冷启动 | < 3s（首屏可交互） |
| 音频播放启动 | 首次播放 < 2s，切歌 < 1s |
| 列表加载 | 分页加载，首屏 < 1s，滚动加载无卡顿 |
| 内存占用 | 常驻内存 < 300MB |
| 歌词同步 | 偏差 < 200ms |
| 窗口切换 | 页面切换无白屏，播放不中断 |

### 6.2 安全

| 要求 | 说明 |
|------|------|
| Token 存储 | JWT Token 使用 Electron safeStorage 或加密存储，不明文写入 localStorage |
| 请求安全 | 所有 API 请求走 HTTPS（生产环境），请求头自动携带 Authorization |
| Token 过期处理 | 401 响应时清除本地 Token，跳转登录页，不 crash |
| 下载安全 | 下载链接使用后端预签名 URL，前端不存储明文凭证 |
| 输入校验 | 搜索/注册/修改密码等输入前端校验 + 后端校验双重保障 |

### 6.3 兼容性

| 维度 | 要求 |
|------|------|
| 操作系统 | Windows 10+、macOS 11+、Ubuntu 20.04+ |
| 屏幕分辨率 | 最低 1280×720，推荐 1920×1080 |
| 网络环境 | 支持弱网降级（自动切换低音质），离线时展示缓存内容 |
| Electron 版本 | 使用最新稳定版 LTS |

### 6.4 可靠性

| 要求 | 说明 |
|------|------|
| 播放连续性 | 页面切换/窗口操作不影响正在播放的音频 |
| 状态恢复 | 应用重启后恢复上次播放状态（歌曲、进度、队列） |
| 错误处理 | 网络错误、播放失败等场景有友好提示，不 crash |
| 日志记录 | 关键操作和错误日志写入本地文件，便于排查 |

## 7. 待确认问题

| # | 问题 | 影响范围 | 建议 |

| Q5 | **是否需要离线播放**：下载后的音乐是否需要在无网络环境下播放？离线播放需要怎样的鉴权？ | 下载管理/离线 | 影响下载文件的加密与播放逻辑 |

| Q7 | **是否需要社交功能**：是否需要评论、分享、关注歌手等社交功能？（当前 API 未包含） | 产品范围 | 确认是否在 v1.0 范围内 |
| Q8 | **多语言支持**：是否需要中英文双语支持？ | UI 设计 | 确认 i18n 需求 |
| Q9 | **自动更新机制**：Electron 应用是否需要内置自动更新（autoUpdater）？还是仅提示用户手动下载？ | 应用更新 | 确认更新策略 |
| Q10 | **用户角色差异**：EDITOR/ADMIN 角色在桌面端播放器中是否有额外功能（如内容管理）？还是播放器仅面向 USER？ | 功能范围 | 确认角色功能边界 |

## 8. 技术方向确认

| 维度 | 选型 | 备注 |
|------|------|------|
| 桌面框架 | Electron | 跨平台，生态成熟 |
| 前端框架 | React 18 + TypeScript | 类型安全，组件化 |
| UI 库 | MUI (Material-UI) + Tailwind CSS | MUI 提供组件基础，Tailwind 提供布局灵活性 |
| 构建工具 | Vite | 快速 HMR，Electron + Vite 集成方案 |
| 状态管理 | Zustand | 轻量，适合播放器全局状态 |
| 音频播放 | HTML5 Audio API | 满足核心播放需求，P2 可视化用 Web Audio API |
| HTTP 客户端 | Axios | 拦截器机制适配 Token 鉴权 |
| 路由 | React Router v6 | 客户端路由 |
| 本地存储 | Electron safeStorage + electron-store | 加密存储 Token，electron-store 存配置 |
