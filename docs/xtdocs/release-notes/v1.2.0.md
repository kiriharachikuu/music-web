# XingTone v1.2.0 更新日志

**版本号：** 1.2.0 (versionCode: 7)  
**发布日期：** 2026 年 7 月 17 日  
**更新类型：** 离线模式全面升级与性能优化

---

## ✨ 新增功能

- **离线模式完整播放器** — 断网后不再只能看歌曲列表，现在支持封面展示、歌词同步、进度拖拽、上下首切换等完整播放体验
- **离线歌词实时高亮** — 支持 LRC 歌词逐行高亮滚动，点击歌词行可跳转到对应位置
- **封面与歌词本地缓存** — 下载歌曲时自动缓存封面图片和歌词到本地，离线时无需联网即可显示
- **音频焦点管理** — 来电、导航播报、通知音等打断后自动恢复播放，支持降低音量共存模式
- **播放打断自动恢复** — 短暂打断（如通知提示）暂停后自动续播，其他 App 抢占音频焦点时正确暂停

## ⚡ 性能优化

- **启动速度提升约 40%** — ExoPlayer、OkHttp Cache、MediaSession 等重组件延迟到后台线程初始化
- **点击响应延迟优化** — 消除偶发 2 秒卡顿，SharedPreferences 读取改为内存缓存
- **通知栏播放器去重** — 仅在状态变化时重建通知，避免每 10 秒重复构建
- **PendingIntent 缓存** — 降低通知栏内存分配频率
- **WebView 配置优化** — URI 解析结果缓存，避免每次 URL 跳转都重新解析
- **SharedPreferences 内存缓存** — 启动时一次性读取，高频访问不再走磁盘 IO

## 🔧 体验改进

- **安装权限按需请求** — 不再在 App 启动时弹出"安装未知应用"权限申请，仅在用户触发更新时才请求
- **离线页面布局优化** — 歌词区域固定高度，不会因内容少而出现大片空白

## 🐛 问题修复

- 修复离线页面封面图片因 WebView 文件访问权限限制无法显示的问题
- 修复离线页面歌词区域溢出导致布局错乱的问题
- 修复离线播放器默认展开而非收起的问题（CSS 选择器优先级错误）
- 修复检测到联网后离线页面自动退出的问题（JS 线程直接操作 WebView 未切回主线程导致崩溃）
- 修复全屏歌词页底部大片空白的布局问题
- 修复 ExoPlayer 内置音频焦点与自定义 AudioManager 焦点管理冲突的问题
