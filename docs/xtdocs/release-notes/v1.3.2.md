# XingTone v1.3.2 更新日志

**版本号：** 1.3.2 (versionCode: 12)  
**发布日期：** 2026 年 8 月 6 日  
**更新类型：** 后台播放稳定性修复（v1.3.1 遗留问题）

---

## 🐛 问题修复

- **修复后台播放偶尔失效且无通知的问题** — v1.3.1 中 `initPlayer()` 在后台线程异步执行，导致 `onStartCommand` 调用 `startForeground` 时 MediaSession 尚未创建，Android 12+ 后台启动时 `mediaPlayback` 豁免无效，`startForeground` 抛出 `ForegroundServiceStartNotAllowedException`，服务退化为后台服务被系统杀死
- **修复返回键逻辑错误** — 原逻辑将 `/live-sessions`、`/search`、`/download`、`/about` 等非主 Tab 页面也判定为根目录，导致这些页面无法返回上一级；且根目录页面会尝试返回上一页而非双击退出

## ⚡ 核心改进

- **播放器同步初始化** — `initPlayer()` 改为在 `onCreate` 主线程同步执行，确保 MediaSession 在 `startForeground` 之前已创建，使 Android 12+ 的 `mediaPlayback` 前台服务豁免生效
- **服务自动重启** — `onStartCommand` 返回值从 `START_NOT_STICKY` 改为 `START_STICKY`，服务被系统杀死后自动重启并恢复前台状态
- **最小化通知可见性** — 从 `VISIBILITY_SECRET` 改为 `VISIBILITY_PRIVATE`，避免部分 OEM ROM 将 `SECRET` 通知完全隐藏导致用户看不到通知
- **返回键逻辑简化** — 4 个主 Tab（`/`、`/rankings`、`/library`、`/profile`）双击退出，不返回上一页；其他页面单次返回上一级

## 🔧 技术细节

| 改动点 | 说明 |
|--------|------|
| `onCreate` | `initPlayer()` 从 `serviceScope.launch` 异步改为同步执行，确保 MediaSession 在 `onStartCommand` 前已创建 |
| `onStartCommand` | 返回 `START_STICKY`，服务被杀后系统自动重启 |
| `startForegroundIfNeeded` | 新增 `ForegroundServiceStartNotAllowedException` 专属捕获，记录 API 版本、MediaSession 状态、App 前后台状态 |
| `buildMinimalNotification` | `VISIBILITY_SECRET` → `VISIBILITY_PRIVATE`，锁屏不显示详情但通知栏可见 |
| 新增 `isAppInForeground()` | 诊断辅助方法，用于日志记录 App 前后台状态 |
| `isRootPath` | 根路径集合精简为 `/`、`/rankings`、`/library`、`/profile` 四个主 Tab |
| `handleOnBackPressed` | 简化逻辑：根目录双击退出不返回，非根目录返回上一级 |
