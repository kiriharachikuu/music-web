# XingTone App v1.3.3 更新日志

**版本号：** 1.3.3 (versionCode: 13)  
**发布日期：** 2026 年 8 月 9 日  
**更新类型：** Android TWA 修复版 / 稳定性更新

---

## 重点修复

- **修复自动更新 APK 下载失败**
  - Android 端安装包下载路径由 `setDestinationUri(Uri.fromFile(...))` 调整为 `setDestinationInExternalFilesDir(...)`
  - 提升 DownloadManager 在不同 Android 版本和模拟器环境下的兼容性

- **修复 TWA 初次启动后页面无法点击**
  - WebView User-Agent 追加 `XingToneTWA/{版本号}`，方便 Web 端识别 TWA 环境
  - WebView 禁用 HTTP 缓存，避免持续命中旧 JS bundle
  - 配合平台端清理 Service Worker / Cache Storage，解决旧 bundle 导致的点击失效问题

- **修复 React 水合异常导致的交互失效**
  - AppShell 改为 client-only 加载，避免服务端与客户端首屏 DOM 不一致
  - 解决 React #418 hydration mismatch 后底部导航、按钮、卡片点击无响应的问题

- **修复下载管理页加载失败**
  - 修复 Zustand selector 每次返回新数组导致的 React #185 最大更新深度错误
  - 下载中任务列表使用稳定 selector + 浅比较，避免渲染死循环

## 下载与离线体验

- **下载管理封面改为服务器文件优先**
  - 在线模式下下载列表封面统一访问服务器封面 URL
  - 不再依赖 `appassets.androidplatform.net` 本地映射，避免 TWA 内封面不显示

- **增强下载管理容错**
  - `formatBytes` 增加异常值保护，避免 undefined / NaN 导致页面崩溃
  - 下载列表跳过异常数据项，避免单条坏数据拖垮整个列表

## 启动画面调整

- **保留开屏品牌文字**
  - 恢复 `XingTone` 品牌文字和 slogan：`用音乐点亮每一刻`
  - 保留品牌文字渐变效果

- **移除开屏底部进度条**
  - 删除进度条轨道和滑块
  - 删除对应动画逻辑，开屏画面更简洁

## 稳定性与错误兜底

- **新增/完善错误边界**
  - 下载管理页具备路由级错误兜底
  - 个人中心 Tab 区域具备组件级错误兜底
  - 全局 `app/error.tsx` 兜底未覆盖路由的运行时错误

- **便于问题定位**
  - 错误页显示错误信息与 digest
  - 提供重试、返回首页、复制错误信息等操作

## 技术细节

| 模块 | 改动 |
|------|------|
| `ApkInstaller` | 下载路径改为 `setDestinationInExternalFilesDir`，补充失败原因解析 |
| `MainActivity` | UA 增加 `XingToneTWA/1.3.3`，WebView 使用 `LOAD_NO_CACHE` |
| `activity_main.xml` | 移除开屏进度条，保留 XingTone 品牌文字和 slogan |
| `downloads-tab.tsx` | 下载封面改为服务器 URL；增强坏数据保护 |
| `download-progress-store.ts` | 修复 selector 返回新数组导致的 #185 死循环 |
| `app-shell-client.tsx` | AppShell client-only，规避 #418 hydration mismatch |
| `error.tsx` | 增加个人中心与全局错误兜底 |
