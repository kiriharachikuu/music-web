# XingTone v1.3.1 更新日志

**版本号：** 1.3.1 (versionCode: 11)  
**发布日期：** 2026 年 8 月 6 日  
**更新类型：** 后台播放稳定性修复

---

## 🐛 问题修复

- **修复后台无法自动切歌的问题** — 歌曲结束后在后台无法自动播放下一首，需手动将省电策略改为"无限制"才能正常工作
- **修复锁屏播放器关闭后后台服务被系统杀死的问题** — 关闭锁屏播放器时 `MediaService` 退化为普通后台服务，被省电策略终止导致播放中断

## ⚡ 核心改进

- **前台服务始终保活** — 播放期间 `MediaService` 始终作为前台服务运行，不再因 `lockScreenPlayer` 开关状态而退化 为后台服务，确保后台播放/切歌不被系统省电策略打断
- **最小化保活通知** — 当用户关闭锁屏播放器时，自动切换为无媒体控件的最小化通知（"正在后台播放"），不在锁屏显示，仅用于维持前台服务存活
- **歌曲切换无缝衔接** — 暂停或歌曲结束时不再立即退出前台服务，仅在用户主动停止播放（unload）时才释放，消除切歌间隙的服务重建开销
- **音频焦点跨歌曲保持** — 歌曲自然结束时不再释放音频焦点，由下一首 `loadAndPlay` 内部重新请求，避免切歌瞬间被其他 App 抢占焦点

## 🔧 技术细节

| 改动点 | 说明 |
|--------|------|
| `startServiceCompat` | 始终使用 `startForegroundService`，不再依赖 `lockScreenPlayerEnabled` |
| `startForegroundIfNeeded` | 移除 `lockScreenPlayerEnabled` 前置检查，关闭时使用最小化通知 |
| `buildMinimalNotification` | 新增：无媒体控件、`VISIBILITY_SECRET` 的极简保活通知 |
| `onIsPlayingChanged` | 暂停/结束时不调用 `stopForegroundCompat`，保持前台状态 |
| `STATE_ENDED` | 不再调用 `abandonAudioFocus`，保持焦点到下一首 |
| `applyLockScreenPlayerSwitch` | 关闭锁屏播放器时切换为最小化通知而非移除前台 |
