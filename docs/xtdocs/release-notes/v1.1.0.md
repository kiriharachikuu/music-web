# XingTone v1.1.0 更新公告

**发布日期**：2026 年 7 月 17 日  
**版本号**：1.1.0（Build 6）  
**更新包大小**：约 4.5 MB

---

## 本次更新亮点

### 锁屏播放器与通知栏控件

现在你可以在锁屏界面和通知栏直接控制音乐播放，无需解锁手机或进入 App。支持播放/暂停、上一首、下一首操作，封面和歌曲信息实时同步显示。

### 性能全面优化

我们对核心模块进行了深度重构，应用启动更快、页面加载更流畅、操作响应更及时：
- API 数据解析速度提升 60% 以上
- 歌曲列表滚动更丝滑，减少卡顿与掉帧
- 封面图加载速度显著提升
- 应用冷启动时间缩短约 50%

---

## 更新内容

### 新增功能
- 锁屏播放器：支持在锁屏界面控制播放，显示封面、歌名、艺术家信息
- 通知栏播放控件：下拉通知栏即可切歌、暂停，信息与 App 内实时同步

### 功能优化
- 修复通知栏上一首按钮有时仅重播当前歌曲的问题
- 修复通知栏概率性卡在"正在准备播放"的问题
- 大幅优化 API 数据解析性能，页面加载速度提升 60%+
- 优化歌曲列表渲染效率，大幅减少滚动卡顿
- 优化播放器进度条渲染性能，降低电量消耗
- 优化应用启动速度，首屏渲染更快进入可交互状态

### 问题修复
- 修复封面图下载连接池未复用导致加载缓慢的问题
- 修复快速切换歌曲时通知栏信息可能不同步的问题

## 安装说明

### 已安装用户
打开 XingTone App，系统将自动检测新版本并提示更新，点击"立即更新"即可。

### 新用户
请访问 [https://xtmusic.chikuu.top](https://xtmusic.chikuu.top) 下载最新安装包。

### 手动安装
1. 下载 APK 安装包至手机
2. 前往「设置 → 安全 → 允许安装未知来源应用」
3. 点击 APK 文件完成安装
